# Download Organiser
A simple Hard Coded Downloads Organiser

Wrote this in 2021 with little Python Knowledge.
It is a hard coded, if-else infinite loop which searches for specific "dot" extensions in the downloads folder and sorts them 
accordingly to a folder named ".(extension)"

Looking back, it would have been better to use a config file for user customisation and useing python dictionaries to better
parse and sort the files.
